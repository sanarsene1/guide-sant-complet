# Homepage photographs

Image bytes are hosted by Lovable Assets. Pointer files are committed alongside this document. The homepage uses absolute URLs on the owning project's preview hostname, rather than project-relative asset URLs, so a GitHub ZIP imported under another account can still request the photographs from the owning project. Keep the owning project and its assets available; removing them will break those remote references. This is not an offline ZIP.

- Hero: original two-dog photo recovered from the source project and uploaded to this project (`home-dogs.jpg.asset.json`).
- Animals: Unsplash, original photo endpoint `https://images.unsplash.com/photo-1552053831-71594a27632d`, resized to WebP.
- Diseases: Yaraazz, https://commons.wikimedia.org/wiki/File:Cerdo_con_PRRS.jpg, CC BY-SA 4.0, resized to WebP. The photograph documents a piglet with PRRS; it is not a generated clinical image.
- Advice: US Army Africa, https://commons.wikimedia.org/wiki/File:Veterinary_Outreach_Hawaye_Kebele_Ethiopia.jpg, CC BY 2.0, resized to WebP.
- Quiz: Monstera Production, https://www.pexels.com/photo/black-students-reading-assignment-in-textbook-6238045/, Pexels license, resized to WebP.
